# RetentionOps AI Platform

RetentionOps is a production-style MLOps/LLMOps project for a fictional fitness SaaS platform.

It demonstrates how to build an end-to-end AI platform on AWS that helps fitness studios identify members at risk of churn, recommend next-best retention actions, and generate grounded staff-facing communication using synthetic data and fictional business documents.

This project is not affiliated with, endorsed by, or based on any specific company or proprietary system. All data, documents, entities and scenarios are synthetic and created for learning and portfolio purposes.

## Goals

- Build a reproducible ML pipeline for churn prediction.
- Serve batch and online predictions.
- Track experiments and model versions.
- Monitor data quality, drift, latency and prediction quality.
- Add a next-best-action recommendation layer.
- Build a RAG assistant over fictional retention playbooks.
- Deploy selected components on AWS using infrastructure as code.
